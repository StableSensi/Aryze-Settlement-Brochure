# Aryze, Nordic Fintech Week 2026

The interactive brochure as a single static page. Everything is embedded in index.html, so there are no dependencies and no build step.

## Run locally

Open index.html in a browser.

## Deploy on Vercel

1. Push this folder to a Git repository.
2. Import the repository in Vercel.
3. Framework preset: Other. Build command: none. Output directory: the repository root.

The page is served as static files. Nothing else is required.
