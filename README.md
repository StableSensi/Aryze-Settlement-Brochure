# Aryze Nordic Fintech Week 2026 brochure

An interactive, self contained HTML brochure for Nordic Fintech Week 2026. It reads as a page turning book on the settlement layer for financial institutions, covering the stack, walletless settlement, cross border settlement, the blockchain connector, how Aryze compares, the team, and the next step.

## Viewing

Open `aryze-nfw-brochure.html` in any modern browser. Everything is embedded in the single file, so there is no server or build step. On desktop it turns as a two page spread; on phone it becomes a single column reader.

## Structure

- `aryze-nfw-brochure.html` is the brochure, one self contained file.
- `design/` holds design references and source plates.
- `docs/` holds planning notes and specifications.

## Interaction

The pages respond to the reader. The stack builds into the bank, the walletless route draws itself, the cross border spread runs a settlement over a live clock with real day and night, and the connector plugs the core into the networks. Fonts load from Google Fonts with local fallbacks.
